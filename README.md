# FranceInfo

Web portal izrađen u PHP-u i MySQL-u kao projekt za kolegije Programiranje web aplikacija i Podatkovna povezanost i digitalna infrastruktura.

## Funkcionalnosti

* Prikaz vijesti
* Prikaz vijesti po kategorijama
* Administracija vijesti (CRUD)
* Registracija korisnika
* Prijava i odjava korisnika
* Administratorske ovlasti
* Vremenska prognoza za francuske gradove
* REST API integracija
* JSON obrada podataka

## Korištene tehnologije

* PHP
* MySQL
* HTML5
* CSS3
* REST API (Open-Meteo)
* JSON

## Pokretanje projekta

1. Kopirati projekt u `htdocs` direktorij XAMPP-a.
2. Pokrenuti Apache i MySQL servis.
3. U phpMyAdmin-u kreirati bazu podataka.
4. Importati datoteku `franceinfo.sql`.
5. Otvoriti:

http://localhost/FranceInfo/index.php
